# First Light

“The sun is rising. Take a breath, and let the story begin.”

[voice.wav](voice.wav) is a 4.923-second, 22.05 kHz mono English recording generated by IndexTTS2. The voice reference is [reference.wav](reference.wav), synthesized with Windows SAPI. [example.json](example.json) contains Qwen3 English forced-alignment estimates, provenance and four bounded pitch control points. [generation.json](generation.json) records the seed and generation settings; [preview.wav](preview.wav) applies the preset curve in one whole-recording resynthesis pass.

The independent SenseVoice transcript check in [verification.json](verification.json) matches the requested words, ignoring punctuation and case.

The workbench copies the example into your workspace before editing it. The repository recording stays unchanged. Open the editor, adjust a point, click Preview and compare the result. Generate a system-voice take or configure an AI engine to explore candidate versions.
